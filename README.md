# WriteWand releases

Downloads and automatic updates for [WriteWand](https://writewand.com), the AI writing assistant for macOS and Windows by Lamino GmbH.

## Download

Get the latest version from [Releases](https://github.com/laminogmbh/writewand-releases/releases/latest):

- **macOS 11 or later**: the `.dmg` file
- **Windows 10 or 11**: the `-setup.exe` file

Installed apps update themselves; this repository only hosts the files they download.
